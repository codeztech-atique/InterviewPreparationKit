🔹 Types of SQL Commands

🏗️ DDL (Data Definition Language)

Used to define and manage database schema.
Commands:

CREATE ➝ Create new database objects (tables, views, etc.)

ALTER ➝ Modify existing schema objects

RENAME ➝ Rename a table or column

TRUNCATE ➝ Remove all records from a table (but keep structure)

DROP ➝ Delete database objects

🔍 DQL (Data Query Language)

Used to query data.
Commands:

SELECT ➝ Retrieve data from database

✏️ DML (Data Manipulation Language)

Used to manipulate data in tables.
Commands:

INSERT ➝ Add new records

UPDATE ➝ Modify existing records

DELETE ➝ Remove records

MERGE ➝ Insert or update records depending on condition (missing in your list ✅)

🔐 DCL (Data Control Language)

Used to control access to data.
Commands:

GRANT ➝ Give user access privileges

REVOKE ➝ Remove user access privileges

🔄 TCL (Transaction Control Language)

Used to manage transactions in a database.
Commands:

START TRANSACTION / BEGIN ➝ Start a transaction

COMMIT ➝ Save changes permanently

ROLLBACK ➝ Undo changes

SAVEPOINT ➝ Set a point to rollback partially (missing in your list ✅)

SET TRANSACTION ➝ Define transaction properties
