| Principle | Meaning                  | Goal                                               |
| --------- | ------------------------ | -------------------------------------------------- |
| **YAGNI** | You Aren’t Gonna Need It | Don’t build features until they’re actually needed |
| **KISS**  | Keep It Simple, Stupid   | Keep design/code simple and understandable         |
| **DRY**   | Don’t Repeat Yourself    | Reuse code instead of duplicating logic            |
