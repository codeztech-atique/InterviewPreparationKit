# Prioritized Medium → Hard Problem List (by topic)

Aim: be able to solve these in ~15 minutes (medium) and 25–40 minutes (hard) while talking aloud.

Arrays & Strings
- Two Sum (array/hash)
- Longest Substring Without Repeating Characters (sliding window)
- Maximum Subarray (Kadane)
- Container With Most Water
- Longest Palindromic Substring

Linked Lists
- Reverse Linked List
- Merge Two Sorted Lists
- Linked List Cycle (Floyd)
- Add Two Numbers (linked list)

Stacks & Queues
- Valid Parentheses
- Min Stack
- Queue using two stacks

Hash Tables / Maps
- Group Anagrams
- Top K Frequent Elements
- Subarray Sum Equals K

Sorting / Searching
- Quickselect / K-th largest
- Merge Sort / implement merge
- Binary Search variations (first/last occurrence)

Trees
- Binary Tree Level Order Traversal
- Height of Binary Tree
- Lowest Common Ancestor (binary tree)
- Serialize / Deserialize Binary Tree

Graphs (BFS / DFS)
- Number of Islands
- Course Schedule / Topological Sort
- Shortest Path (Dijkstra) — discuss trade-offs

Dynamic Programming
- Climbing Stairs
- Longest Increasing Subsequence
- Coin Change
- Word Break

Backtracking / Combinatorics
- Permutations
- Combination Sum
- N-Queens (medium/hard)

Heaps / Priority Queue
- Kth Largest Element
- Merge K Sorted Lists

Sliding Window / Two Pointers
- Longest Substring with at most K distinct
- 3Sum / 3Sum Closest

System Design (HLD topics to practice)
- Design a URL shortener (capacity, caching, DB schema)
- Design a feed service (fanout, feed generation)
- Design a rate limiter (algorithms: token bucket, leaky bucket)

Practice guidance
- Pick 3 problems per day: 1 easy (warmup), 1 medium timed (15m), 1 deep-dive (25–40m)
- Track time in `TIMED_PRACTICE.md` and note mistakes for review
