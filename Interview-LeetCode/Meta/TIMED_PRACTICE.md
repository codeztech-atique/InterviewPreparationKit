# Timed Practice & Mock Interview Log

Use this file to schedule, record, and review timed practice sessions.

## Practice cadence (example)
- 5 days/week, 45–60 minutes/day for first 3 weeks
- Weeks 3–4: 3 full mock screens (60m) + 4 timed problems (15m each)

## Session template (copy per session)
- Date: YYYY-MM-DD
- Mode: CoderPad / Whiteboard / Local editor
- Problem(s): title + topic
- Target time: 15m / 35m / 60m
- Actual time:
- Outcome: solved / partial / got stuck
- Key mistakes:
- Next steps to fix:

## Mock interview checklist
- Warm up: 2 easy problems (10–15m)
- Full practice: simulate the 60-minute screen (behavior 10–15m + coding 35–40m)
- Record yourself if possible and review for clarity and pacing

## Weekly review
- Summarize 3 takeaways each week (weak topics, timing issues, communication)
