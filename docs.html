API Platform Overview

Welcome to the Abstrive developer platform. Our REST APIs give you full programmatic access to Atlas analytics, Nexus ticketing, AI Agent workflows, and Nova's conversational AI — all under one unified API. All endpoints are resource-oriented, authenticated via API keys, and return consistent JSON responses.

# Install the Abstrive SDK
npm install @abstrive/sdk

# Authenticate and make your first request
curl https://api.abstrive.io/v1/nexus/tickets \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

Get Started

The Abstrive API uses standard REST conventions with predictable resource-oriented URLs. Authentication is handled via API keys passed as a Bearer token in the request header. All responses return JSON — including errors.

To begin: create an Abstrive workspace, navigate to Settings → API Keys, generate a key, and make your first request using the SDK or raw HTTP. Your key is workspace-scoped and can be rotated at any time.

ⓘ New: Nova API v2 is live — improved response latency, multi-channel support, and RAG knowledge size up to 1GB.

Base URL & Authentication

All API requests are made to https://api.abstrive.io/v1/. Pass your API key as a Bearer token in the Authorization header. Keys are workspace-scoped — one key gives access to all four products (Atlas, Nexus, AI Agents, Nova) based on your plan's permissions.

Authorization: Bearer sk_live_xxxxxxxxxxxxxxxxxxxx
Content-Type: application/json
X-Abstrive-Workspace: your-workspace-id
